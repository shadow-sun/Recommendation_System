# 代码方案.md

## Summary

本工程已按计划实现一个可运行的“离线训练 + 实时特征 + 在线召回排序重排”推荐系统原型。当前版本支持无真实 KuaiLive 数据时生成 sample 数据并跑通完整链路；拿到 KuaiLive 或 ml-100k 原始数据后，可通过 `src/data/adapters.py` 转换为统一交互 schema。

## 已实现模块

- 数据层：统一字段 `user_id,item_id,item_type,timestamp,behavior_type,label,category,source_dataset`，支持 KuaiLive/ml-100k 适配和时间切分。
- 模型层：热门推荐 baseline、双塔 embedding 召回、Faiss 兼容向量索引 fallback、DeepFM 风格排序器。
- 实时层：内存 FeatureStore 和 streaming fallback，维护用户近期行为、物品热度、策略配置和负反馈类目降权。
- 在线服务：FastAPI 提供 `/health`、`/recommend`、`/feedback`、`/metrics/summary`、`/admin/strategy`。
- 重排层：MMR 多样性重排，结合相关性、embedding 相似度和负反馈 penalty。
- 仿真与评估：闭环脚本输出推荐延迟、负反馈前后类目变化、ILS 多样性等指标。
- 部署：提供 `requirements.txt`、`Dockerfile`、`docker-compose.yml`。

## 运行命令

```bash
cd recommendation-system
pip install -r requirements.txt
$env:PYTHONPATH="."
python scripts/run_demo.py
python scripts/run_simulation.py
uvicorn src.services.api:app --reload --host 127.0.0.1 --port 8000
```

## 测试命令

```bash
cd recommendation-system
$env:PYTHONPATH="."
pytest -q
```

如果当前 Python 环境尚未安装 pytest，可运行：

```bash
cd recommendation-system
$env:PYTHONPATH="."
python scripts/smoke_test.py
```

## 后续接入真实数据

- 将 KuaiLive 或 ml-100k 放入 `data/raw/`。
- 调用 `src.data.load_interactions([...])` 生成统一 DataFrame。
- 用统一 DataFrame 替换 `build_demo_gateway()` 中的 sample 数据来源。
- 若部署完整 Kafka/Flink/Redis，可将当前 `FeatureStore` 替换为 Redis 客户端实现，保留相同业务接口。
